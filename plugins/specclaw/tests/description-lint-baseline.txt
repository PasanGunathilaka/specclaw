# description-lint-baseline.txt — offences that predate the rule.
#
# Pairs of `<path> <RULE>`, no line numbers, so an unrelated edit to a SKILL.md
# never churns this file. run-description-lint-tests.sh fails on anything NOT
# listed here, and reports listed entries that no longer offend so the list can
# only shrink.
#
# THIS IS A DEBT REGISTER, NOT A LICENCE. Every entry is a description written
# before the rule existed. A NEW skill gets no entries and must pass the rules
# from its first commit — `skills/debug` and `skills/using-specclaw`, added
# alongside this lint, are not in here.
#
# The rewrite that clears these is deliberately NOT in the same change as the
# lint: proposal 037 requires a before/after trigger matrix as the evidence that
# a rewrite helped, and this file ships with the suite that produces it. Clear
# entries skill-by-skill, with a matrix, not in one sweep.
#
#   SPECCLAW_TRIGGER_EVALS=1 bash plugins/specclaw/tests/run-trigger-tests.sh
#
# Never add an entry to silence a description you just wrote.
#
# Emptied by change 042: every description is one trigger-first sentence.
